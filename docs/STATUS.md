# 当前项目状态

更新时间：2026-10-18（Asia/Shanghai）

## 1. 总体状态

当前处于“RUL/SOH 原型已跑通，正在进行严谨对比和实验固化”阶段。

## 2. 已完成且验证通过

- MATR 预处理数据可读取，`data/processed/MATR` 有 180 个 `.pkl` 文件。
- 作者 RUL XGBoost 基线可运行，结果约 RMSE 333.6646。
- 累计差分、相邻差分和组合差分已完成实验。
- RUL 滚动窗口、RUL≥300、PCA50 流程已运行。
- 滚动 RUL 结果支持电芯级宏平均和窗口级指标。
- SOH 逐循环标签接口已实现。
- 作者 SOH XGBoost 基线已运行：RMSE 0.009663，MAE 0.007932，MAPE 0.81195%。
- SOH 滚动方案已运行：全窗口电芯宏平均 RMSE 0.012373，MAE 0.010066，MAPE 1.08677%。
- SOH 第98循环对齐比较已完成：滚动方案 RMSE 变差约6.70%，MAE/MAPE改善约3.34%。
- SOH 固定第98循环特征消融已完成：累计参考差分+相邻差分 RMSE 0.009345，优于作者基线 RMSE 0.009663。
- SOH 不同观测点验证已完成：组合差分在第98循环有效，第70循环基本持平，第50循环变差，存在阶段依赖性。
- 滚动 SOH 的 PCA 对比已完成：在相同降采样设置下，无 PCA 优于 PCA50，但该结论尚未经过多 seed 验证。
- 完整特征无 PCA 滚动尝试失败：窗口构建阶段需要约19.2 GiB额外内存，当前实现需要改为懒加载或分块处理。
- 统计聚合滚动 SOH 已实现并验证：20区间均值+标准差方案 RMSE 0.010796，内存可控。
- 关键问题和复现命令已归档。

## 3. 已实现但需要继续验证

- 电芯等权评价代码已实现，但需要在多个任务和多个随机种子上复核。
- SOH 任务复用了 `XGBoostRULPredictor` 类名，功能上是通用回归；后续可增加更清晰的 `XGBoostRegressor` 别名。
- 当前滚动结果的部分循环元数据需要进一步显式保存，减少后处理重建。

## 4. 尚未完成

- 多随机种子实验和置信区间。
- RUL/SOH 每电芯误差、阶段误差和离群电芯分析。
- 对 SOH 方案进行 PCA、不同窗口长度和不同特征组合的进一步消融实验。
- Isolation Forest 异常检测模块及可复现 F1 结果。
- LSTM/Transformer 与 XGBoost 的同口径对比。
- 预测不确定性和置信区间。
- Agent/MCP 工具服务和报告生成原型。
- 真实运营数据/跨工况验证。

## 5. 当前已知阻塞

1. 实验运行环境完整版本尚未归档。
2. SOH 组合差分提升具有观测阶段依赖性，尚未形成统一的全阶段最优方案。
3. PCA 对滚动 SOH 的影响仍需在更多随机种子和不同降采样设置下确认。
4. 当前滚动窗口实现会一次性物化全部窗口，完整特征无 PCA 无法运行。
5. 统计聚合的区间数量和统计量组合尚未优化。
