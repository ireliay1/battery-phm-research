# 当前项目状态

更新时间：2026-10-20（Asia/Shanghai）

## 1. 总体状态

当前处于“RUL/SOH 原型已跑通，正在进行严谨对比和实验固化”阶段。

## 2. 已完成且验证通过

- MATR 预处理数据可读取，`data/processed/MATR` 有 180 个 `.pkl` 文件。
- 作者 RUL XGBoost 基线可运行，结果约 RMSE 333.6646。
- 累计差分、相邻差分和组合差分已完成实验。
- RUL 滚动窗口、RUL≥300、PCA50 流程已运行。
- 滚动 RUL 结果支持电芯级宏平均和窗口级指标。
- SOH 逐循环标签接口已实现。
- 作者 SOH XGBoost 基线已运行：RMSE 0.009663，MAE 0.007932，MAPE 0.81195%。
- SOH 滚动方案已运行：全窗口电芯宏平均 RMSE 0.012373，MAE 0.010066，MAPE 1.08677%。
- SOH 第98循环对齐比较已完成：滚动方案 RMSE 变差约6.70%，MAE/MAPE改善约3.34%。
- SOH 固定第98循环特征消融已完成：累计参考差分+相邻差分 RMSE 0.009345，优于作者基线 RMSE 0.009663。
- SOH 不同观测点验证已完成：组合差分在第98循环有效，第70循环基本持平，第50循环变差，存在阶段依赖性。
- 滚动 SOH 的 PCA 对比已完成：在相同降采样设置下，无 PCA 优于 PCA50，但该结论尚未经过多 seed 验证。
- 完整特征无 PCA 滚动尝试失败：窗口构建阶段需要约19.2 GiB额外内存，当前实现需要改为懒加载或分块处理。
- 统计聚合滚动 SOH 已实现并验证：20区间均值+标准差方案 RMSE 0.010796，内存可控。
- 统计聚合滚动 SOH 已完成 seed 0–3 验证，四组结果完全一致；当前 XGBoost 配置基本为确定性训练。
- 统计聚合迁移到滚动 RUL 后已完成初步对比：电芯宏平均 RMSE 69.592，优于 PCA50 的 94.853，但目前仅 seed=0。
- 已实现并完成电压方向 dQ/dV 特征对照：SOH 电芯宏平均 RMSE 0.010573，较统计聚合基线小幅改善；RUL 电芯宏平均 RMSE 75.078，较统计聚合基线变差。
- 已实现并验证温度/内阻特征追加：SOH 电芯宏平均 RMSE 0.010893，RUL 电芯宏平均 RMSE 97.871，均未超过统计聚合基线。
- 已建立 Isolation Forest + MAD 阈值实验脚本；`k=3.5` 初步测试未在真实 MATR 测试集触发报警，合成异常 F1 为0，说明阈值或异常构造仍需调整，当前不能作为有效异常检测结果。
- 已接入 Tsinghua EV 品牌1数据并完成车辆级 Isolation Forest 基线；简单统计特征下 F1 为0、AUROC为0.541，当前特征表示和阈值策略不能有效区分真实异常车辆。
- 已将 Tsinghua EV 阈值改为独立正常车辆的99%分位数；F1提升至0.125、Precision为1.0，但Recall仅0.0667，AUROC仍为0.541，说明阈值不是主要瓶颈。
- 已实现 Tsinghua EV 动态/机理特征分支：电压一致性、温度变化率以及 SOC/电流到电压/温度的正常响应残差；代码已通过语法检查，但品牌1完整实验因压缩包逐文件扫描和特征提取耗时过长尚未完成验证。
- Tsinghua EV 脚本已支持从已解压的品牌目录读取数据，避免重复扫描压缩包；动态特征全量实验已尝试但因品牌1逐文件反序列化耗时过长中止，尚无新的性能结果。
- 已增加 Tsinghua EV 车辆级分布特征 Isolation Forest 分支（片段特征的均值、标准差及 P10/P50/P90），但全量验证同样受逐文件读取瓶颈影响而中止，尚无新的 F1 结果。
- 已补跑作者 Ridge、随机森林和 LSTM RUL 基线：RMSE 分别为 115.789、164.312 和 112.528；三者输入口径不同，暂不作严格模型排名。
- 已补跑同口径 SOH Ridge、随机森林和 LSTM 基线：RMSE 分别为 0.010810、0.008819 和 0.010846；随机森林在单 seed 下优于作者 XGBoost SOH 基线。
- 关键问题和复现命令已归档。

## 3. 已实现但需要继续验证

- 电芯等权评价代码已实现，但需要在多个任务和多个随机种子上复核。
- SOH 任务复用了 `XGBoostRULPredictor` 类名，功能上是通用回归；后续可增加更清晰的 `XGBoostRegressor` 别名。
- 当前滚动结果的部分循环元数据需要进一步显式保存，减少后处理重建。

- Isolation Forest 的稳定真实故障检测结果；Tsinghua EV 已有第一版真实标签基线，但仍需独立正常验证车辆、动态特征和多品牌验证。

- 预测不确定性和置信区间。

- 真实运营数据/跨工况验证。

## 5. 当前已知阻塞

1. 实验运行环境完整版本尚未归档。
2. SOH 组合差分提升具有观测阶段依赖性，尚未形成统一的全阶段最优方案。
3. PCA 对滚动 SOH 的影响仍需在不同降采样设置下确认；统计聚合已完成 seed 0–3 验证。
4. 当前滚动窗口实现会一次性物化全部窗口，完整特征无 PCA 无法运行。
5. Tsinghua EV 品牌1动态特征实验当前逐文件读取压缩包较慢，尚未生成可复现性能结果；需要先解压为普通文件或缓存特征。
5. 统计聚合的区间数量和统计量组合尚未优化。
6. dQ/dV 特征目前只完成单 seed 验证，SOH 的小幅改善和 RUL 的退化仍需多 seed 及平滑参数消融确认。
7. 温度/内阻当前仅使用单循环统计量；需要进一步验证内阻增长量和温度应力累积等退化特征。

## 6. 下一步优先级

1. 保存 Python、PyTorch、scikit-learn、XGBoost 版本。
2. 为滚动预测结果保存 `cell_id`、窗口起止循环和标签。
3. 对作者 SOH 基线和滚动方案运行多个随机种子。

### P1：继续优化 SOH

1. 输出每个电芯的 RMSE/MAE/MAPE。
2. 找出离群电芯并检查其容量曲线和标签质量。
3. 分析第50/70/98循环的特征分布差异，确定是否需要阶段自适应特征策略。
4. 验证无 PCA 结果在不同 `cycle_average` 和随机种子下是否稳定。
5. 优化滚动数据集构建，支持懒加载或分块处理后再做完整特征无 PCA 对比。
6. 对统计聚合做区间数量和统计量消融。
7. 如需验证随机训练鲁棒性，显式设置 XGBoost `random_state`、`subsample` 和 `colsample_bytree` 后再做多 seed 实验。
8. 对统计聚合 RUL 方案运行多 seed 验证。
9. 对 dQ/dV 增强方案运行多 seed，并分析其对 SOH/RUL 任务产生不同影响的原因。
10. 将温度/内阻特征拆分消融，优先测试内阻增长量、温度变化量和高温暴露时间。

### P2：扩展 PHM 能力

1. 比较 Isolation Forest 的分位数阈值和连续超阈值报警规则。
2. 构造或整理带故障标签的异常数据，重新评价 Precision、Recall、F1 和提前预警时间。
3. 在 Tsinghua EV 上加入 SOC 条件下的电压响应、温度变化率、充电时长和电压一致性等动态/机理特征。
4. 将正常车辆拆分为模型拟合集和阈值校准集，并比较 MAD 与高分位数阈值。
5. 对比 LSTM/Transformer。
6. 封装模型推理接口，再设计 Agent/MCP 调用层。
