# 项目说明

## 1. 项目背景

本项目以 BatteryML 为基础，使用公开锂电池循环数据搭建动力电池 PHM（Prognostics and Health Management）原型，服务于动力电池算法工程和电池安全/健康管理方向的学习与面试准备。

技术路线：

```text
工业故障诊断 → 动力电池 PHM → 电池智能 Agent / 工业 AI 应用
```

## 2. 核心目标

1. 理解 BatteryML 的 `BatteryData`、配置、预处理和训练评估流程。
2. 完成 MATR 电芯循环数据的特征提取、SOH/RUL 标签构造和模型训练。
3. 以作者原始 XGBoost 方法作为基线，评估特征、滚动窗口和降维策略的影响。
4. 建立合理的数据划分、滑窗、防泄露和电芯级评价规范。
5. 扩展 Isolation Forest 异常检测，并为后续 Agent 工具调用和业务闭环做准备。

## 3. 当前研究问题

### RUL

在 MATR Primary 划分上，使用循环退化特征预测从当前循环到 SOH 下降至 80% 的剩余循环数。当前改进方案采用 50 个循环滚动窗口，并在离线实验中仅保留真实 RUL 不小于 300 的样本。

### SOH

SOH 定义为当前放电容量与额定容量的比值。当前已实现两个 XGBoost 实验：作者单循环方案作为基线，以及累计退化/相邻变化特征加 50 循环窗口的实验方案。

### 异常检测

计划使用电压、温度、容量和内阻等运行特征建立 Isolation Forest 无监督异常检测模块。当前尚未在本项目结果目录中确认可复现的 F1 实验结果。

### Agent

计划将数据查询、RUL/SOH 推理、异常解释和报告生成封装为工具，再由 Agent 进行任务理解和流程编排。当前尚未实现可复现的 Agent 服务。

## 4. 约束

- 训练和测试必须按电芯划分，不能让同一电芯的窗口跨越训练/测试边界。
- 有状态的数据变换只能使用训练集拟合，测试集只能变换。
- 实验必须保存配置、命令、随机种子、工作区和原始结果文件。
- 不把作者基线包装为原创成果。
- 不把预期指标写成已取得结果。
- 当前项目没有有效 Git 历史；代码版本只能以文件和实验归档追溯。

## 5. 成功标准

### 已确认的阶段性标准

- 能够运行作者 RUL XGBoost 基线并保存结果；
- 能够运行 SOH XGBoost 基线和滚动窗口实验；
- 能够解释标签、特征、滑窗、PCA、数据泄露和评价指标；
- 每个实验可以从配置和工作区复现。

### 尚未完成的标准

- 多随机种子均值和标准差；
- 每电芯误差和不同 SOH/RUL 阶段误差分析；
- Isolation Forest 测试集 F1 ≥ 0.70 的可复现实验；
- Agent/MCP 工具化原型；
- 真实运营数据或跨工况验证。
