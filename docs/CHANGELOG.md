- PCA 改为在单循环特征层面拟合，之后再构造滚动窗口。

## 2026-10-19

### 统计聚合特征

- 新增 Qdlin 差分曲线的等区间均值+标准差聚合，支持通过 `aggregation_bins` 配置。
- 新增滚动 SOH 统计聚合实验配置，20区间方案在单 seed 下成功运行，电芯宏平均 RMSE 为 0.010796。
- 记录完整特征无 PCA 因一次性构造窗口导致约19.2 GiB内存分配失败的问题。
- 完成统计聚合滚动 SOH 的 seed 0–3 验证；由于当前 XGBoost 配置为确定性训练，四组结果一致。
- 将统计聚合特征迁移到 RUL 滚动预测，seed 0 下电芯宏平均 RMSE 为 69.592，优于 PCA50 方案。

## 2026-10-20

### 电压方向差分特征

- 在 `VoltageCapacityMatrixFeatureExtractor` 中新增 `include_voltage_gradient` 配置，用统一电压网格上的 `numpy.gradient` 近似 Qdlin 的 (dQ/dV)。
- dQ/dV 在参考差分和循环相邻差分两个通道上分别计算，并继续使用20区间均值+标准差聚合。
- 完成滚动 SOH 对照：电芯宏平均 RMSE 从 0.010796 降至 0.010573。
- 完成滚动 RUL 对照：电芯宏平均 RMSE 从 69.592 增至 75.078，当前不支持将 dQ/dV 直接加入 RUL 方案。

### 温度与内阻机理特征

- 新增 `include_temperature_resistance` 配置，追加每循环温度均值、最大值、最小值、范围、标准差和内阻。
- 修复缓存签名未包含字典参数名导致的配置碰撞，并重新运行有效实验。
- 温度/内阻特征加入后，SOH 电芯宏平均 RMSE 为 0.010893，RUL 电芯宏平均 RMSE 为 97.871，均未改善统计聚合基线。
- 补跑作者 MATR Ridge、随机森林和 LSTM RUL 基线，记录其 RMSE/MAE/MAPE 及输入口径差异。
